# WhoAmI

Прототип двумерной сюжетной игры на Godot 4.6. Игрок управляет Михаилом,
исследует комнаты дома, разговаривает с персонажами и собирает предметы.
Игровая логика написана на GDScript.

## Что есть в проекте

- Четыре комнаты: спальня, коридор, кухня и ванная.
- Переходы между комнатами через двери.
- Осмотр предметов и диалоги с постепенным появлением текста.
- Сбор предметов из контейнеров по одному или кнопкой «Забрать всё».
- Главное меню и меню паузы.
- Общее состояние игры: сюжетные флаги и список собранных предметов.

## Запуск

1. Установите Godot 4.6 — эта версия указана в
   [настройках проекта](project.godot). Проект использует рендерер Forward Plus.
2. В менеджере проектов Godot нажмите **Импортировать** и выберите
   `project.godot` из корня репозитория.
3. Откройте проект и дождитесь импорта ресурсов.
4. Нажмите **F5**, чтобы запустить игру с главного меню.
5. Выберите **Новая игра**, чтобы начать в спальне.

Если команда `godot` доступна в `PATH`, открыть редактор можно из корня
репозитория:

```bash
godot --editor --path .
```

Для запуска игры из терминала:

```bash
godot --path .
```

## Управление

| Клавиша или действие | Назначение |
| --- | --- |
| `A` / `D` | Движение влево / вправо |
| `E` рядом с объектом | Осмотр, разговор или переход через дверь |
| `E` во время диалога | Показать реплику целиком или перейти к следующей |
| `E` в открытом контейнере | Закрыть контейнер |
| `Esc` | Закрыть активное окно либо открыть / закрыть меню паузы |
| Двойной щелчок левой кнопкой мыши по предмету | Забрать предмет из контейнера |

Доступное взаимодействие отображается в подсказке на экране.

## Структура репозитория

```text
WhoAmI/
├── project.godot          # Настройки Godot, главная сцена и Input Map
├── scenes/
│   ├── characters/       # Сцены персонажей
│   ├── rooms/            # Комнаты и объекты комнат
│   └── ui/               # Меню, диалоги и панели
├── scripts/
│   ├── core/             # Логика комнат и GameState
│   ├── player/           # Движение игрока и выбор объекта взаимодействия
│   ├── interaction/      # Поведение интерактивных объектов
│   ├── dialogue/         # Управление диалогами
│   ├── transitions/      # Переходы через двери
│   ├── UI/               # Скрипты интерфейса
│   └── effects/          # Шейдеры и визуальные эффекты
├── art/                  # Фоны, персонажи и предметы
└── loot_item.tscn         # Карточка предмета в контейнере
```

Главная сцена — `scenes/ui/MainMenu.tscn`. Автозагрузка `GameState`
находится в `scripts/core/game_state.gd` и хранит состояние между комнатами.
Обратите внимание на регистр: сцены интерфейса находятся в `scenes/ui/`,
а их скрипты — в `scripts/UI/`.

## Текущее состояние

Игра находится в разработке. Некоторые элементы пока подготовлены частично:

- `GameState` содержит методы `save_game()` и `load_game()` для файла
  `user://savegame.json`, но экраны сохранения и загрузки пока содержат
  только кнопку возврата и не вызывают эти методы.
- Собранные предметы хранятся в `GameState.inventory`. Отдельный экран
  `scenes/ui/Inventory.tscn` пока является заготовкой.
- Действия `move_up`, `move_down` и `inventory` назначены на `W`, `S` и `I`
  в Input Map, но текущая игровая логика их не обрабатывает.
- Экран настроек пока содержит навигацию назад; изменение параметров
  игры не реализовано.
